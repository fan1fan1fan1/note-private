一.将ollama与n8n联用

	启动ollama 已知端口http://localhost:5678
	n8n中通过表单提交触发，n8n调用ollama本地运行的模型形成指定内容的文案，并将结果通过http响应返回至邮件


	1.webhook节点
		Listen for test event 生成唯一的webhook URL  (左侧)
		定义期望收到的输入字段 json格式  (右侧)


	2.HTTP Request节点
		1.post
		2.URL: http://localhost:11434/api/generate 
			(此接口为ollama官方本地生成接口)
		3.Header: Content-Type: application/json
		4.Body: json
```
{  
  "model": "qwen", // 替换为你运行的模型（如 mistral、phi2 等）  
  "prompt": "请为产品 {{$json.name}} 生成营销文案，突出以下卖点：{{$json.code}}。要求语言生动，适合社交媒体传播。",  
  "temperature": 0.7, // 控制生成随机性（0.0-1.0）  
  "max_tokens": 200 // 最大生成字数  
}			
```
		5.输出处理: Ollamqa返回结果包含在response.body.content字段中
				   需要提取文本

			
	3.Set节点   (Edit Fields)  

	添加set节点 从HTTP响应中提取文案并格式化(4.)
		1.点击红色 Add Field 
		2.新增字段generatedContent  
			值为{{$json.response.body.content}}
			
				Ollama的API响应式json格式 
				生成内容在json.response.body.content里
				所以我们通过set使用{{$}}提取content
				最后通过HTTP返回到body
				
		3.可选: 添加时间戳或其他元数据
		
		(解释:  Ollama响应json数据中的content元素 
			    通过response {{$}}得到数据
			    再通过set节点返回
			    最后用HTTP输出结果
		)

	4.添加HTTP Response节点
