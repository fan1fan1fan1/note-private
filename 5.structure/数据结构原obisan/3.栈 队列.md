栈案例三 表达式求值
/*
     由运算符优先级确定运算顺序的对表达式求值算法

     算符优先算法

  
     操作符: 常数 变量

     运算符: 算术运算符 关系运算符 逻辑运算符

     界限符: 左右括弧 表达式结束符

  
     任何一个算术表达式都由操作数 算术运算符 界限符组成    后两者统称算符

  
     eg. # 3 * (7 - 2) #

	为了实现表达式求值 需要设置两个栈:

          1.一个是算符栈OPTR 用于寄存运算符

          2.另一个称为操作数栈OPND 用于寄存运算数和运算结果

  
          如果扫描运算数 放到OPND

          如果扫描运算符 放到 (1) 优先级高于OPTR栈顶的运算符 进入OPTR

                             (2) 优先级低于OPTR栈顶的运算符 从OPND中弹出两个运算符

	                             从OPTR中弹出栈顶运算符进行比较 将运算结果压入栈OPND
*/


解释

     OPTR 运算符 后进先出

     OPND 数

  
     扫描到运算符的时候进入OPND  
     eg. 3 + 5 * 2 扫到3时 3进入OPND 扫描到5时 5进入OPND

     优先级高的处理                 
     扫描到+ +进入OPTR 扫描到* *进入OPTR此时 * 优先级高于 +
     于是将 5和2 从OPND中弹出 计算5*2结果 将结果放进OPND                        
     最后计算+

/* 顺序栈

     线性表顺序存储结构  一组连续的存储单元

     一般栈底为低地址端

  

     附设top指针 指栈顶 但是为了方便 通常让top指向栈顶元素之上的下标地址(不存在的元素an+1)

     另设base指针 指栈底

     另外设 stacksize表示栈可使用的最大容量 用数组存储栈

  

     (栈顶top) an -> an-1 -> ... -> a2 -> a1 (栈底base)

  

     空栈的标志: base和top指向同一个位置 且为空  base == top

  

     eg. stacksize = 4 有4个位置

          假设有元素A入栈 top位置上移一个 A为base位置

          A -> B -> C -> D 此时栈满 top指向D的下一个位置

     栈满标志: top指针和base指针的差值 达到了stacksize     top - base == stacksize

     当top - base > stacksize 上溢overflow 溢出 通常上溢时错误的

  

     栈满的处理方法:

          1.报错 返回操作系统

          2.分配更大的空间 作为栈的存储空间 将原来的内容移入这个新栈

  

     出栈时 每出一个元素 top位置下移一个

     当出到最后一个元素后 再出栈 下溢underflow 溢出 下溢可以作为一种结束条件
*/



1.顺序栈的定义
```
#define MAXSIZE 100

typedef struct{

     SElemType *base;   // 栈底指针

     SElemType *top;    // 栈顶指针

     int stacksize;     // 栈可用最大容量

}SqStack;
```




2.顺序栈的初始化

注: 如果需要分配的栈的空间 非常大 初始化可能不成功
```
Status InltStack(SqStack &S){           // 构造一个空栈

     S.base = new SElemType[MAXSIZE];  

     // S.base = (SElemType*)malloc(MAXSIZE*sizeof(SElemType));  c语言

  
     if(!S.base) exit (OVERFLOW);       // 存储分配失败

  

     S.top = S.base;                    // 栈顶指针等于栈底指针

  

     S.stacksize = MAXSIZE;

  

     return OK;
}
```

4.链栈入栈

// 分配一块内存 赋值给指针p 插入栈顶; 将p -> next域赋值 赋为原来栈顶元素
```
Status Push(LinkStack &S, SElemType e){

     p = new StackNode;   // 生成新结点p

     p -> data = e;       // e为新结点数据域

     p -> next = S;       // 将新结点插入栈顶

     return OK;
}
```

```
     return OK;
```

*/

```
typedef struct{

     QElemType *base;  // 初始化的动态分配存储空间

     int front;        // 头指针

     int rear;         // 尾指针

}SqQueue;
```



/* 队列操作

     初始        front = rear = 0

     当有元素入队 base[rear] = x;  (在最后入队)

                 rear++;   每一次入队 尾指针向后移

     出队(队头出) x = base[front];

                 front++;  拿出元素后 头指针向后移 头指针要指向元素

                 此时在队尾的元素位置不变 前边的元素为空

     空队列的标志 front = rear

*/

  
  
/* 溢出问题的解决

     设数组大小为MAXQSIZE

     当rear = MAXQSIZE时发生溢出

  

     若front = 0

     rear = MAXQSIZE时 再入队 真溢出

  

     若front != 0

     rear = NAXQSIZE时 再入队 假溢出

  

     eg. 一共有六个元素位置 满   现从队头取出4个 那么前4个位置为空 后两个位置有元素

         如果在增加新的元素到队尾 则会发生溢出 假溢出

  

     解决假上溢问题:

          当前面的元素从队头出队时 将后面的元素前移

          将队列想象成一个循环空间 内存可循环使用

          当rear为maxqsize时 若前面的位置为空 则可从头使用空间

          当front为maxqszie时同理

          --引入循环队列

  

     base[0] 接在 base[MAXQSIZE - 1]之后 若rear+1 == M 则令rear = 0;

     利用取模运算%    2%6=2  3%6=3  ...  6%6=0开始循环

  

     插入元素: Q.base[Q.rear] = x;

              Q.rear=(Q.rear+1) % MAXQSIZE;

     删除元素: x=Q.base[s.front];     只能作用在表头

              Q.front=(Q.front+1) % MAXQSIZE;

*/



/* 队空队满问题

     队空队满的标志相同 front == rear

  

     解决方案:

          1.另外设一个标志以区分队满队空

          2.另设一个变量 记录元素个数

          3.少用一个元素空间***

  

     少用一个元素空间

          队空 front == rear

          队满 (rear + 1 ) % MAXQSIZE == front   即rear比front少一个

  

          指针相同就为空  指针加一相同就为满

*/

  
  
 1.循环队列的定义
```
#define MAXQSIZE 100     // 最大长度队列

typedef struct{

     QElemType *base;    // 动态分配存储空间

     int front;          // 头指针 若队列不为空 指向队列头元素

     int rear;           // 尾指针 若队列不为空 指向队列尾元素的下一个位置

}SqQueue;
```
此处SqQueue不是指针类型 因此调用时不使用-> 使用.

  
  
2.队列的初始化
```
Status InitQueue(SqQueue &Q){

     Q.base = new QElemType[MAXQSIZE] // 分配数组空间

     // c语言中 
     // Q.base = (QElemType*)malloc(MAXQSIZE*sizeof(QElemTypep));


     // 判断是否分配成功

     if(!Q.base)  exit(OVERFLOW);     // 分配失败

     Q.front = Q.rear = 0;            // 头指针尾指针置为0 队列为空

     return OK;
}
```

  

3.求队列的长度
```
int QueueLength(SqQueue Q){

     return ((Q.rear - Q.front + MAXQSIZE) % MAXQSIZE);

}
```


  
4.队列入队
```
Status EnQueue(SqQueue &Q, QElemType e){

     if((Q.rear + 1) % MAXQSIZE == Q.front)   return ERROR;   // 队满

     // 牺牲了一个空间   Q.rear + 1

  

     Q.base[Q.rear] = e;               // 新元素加入队尾

     Q.rear = (Q.rear + 1) % MAXQSIZE; // 队尾指针 + 1

     return OK;
}
```



5.队列出队
```
Status DeQueue(SqQueue &Q, QElemType &e){

     if(Q.front == Q.rear)  return ERROR; // 队空

     e = Q.base[Q.front];                 // 保存队头元素

     Q.front = (Q.front + 1) % MAXQSZIE;  // 队头指针 + 1

     return OK;
}
```

事实上并没有真正删除数据 只是通过移动队头指针Q.front来实现逻辑上的删除

  

6.取队头元素

```
 SElemType GetHead(SqQueue Q){

     if(Q.front != Q.rear)     // 队列不为空

          return Q.base[Q.front]  // 返回队头指针元素的值 队头指针不变
 }
```

/* 链队列

     Q.front 头指针 指向头结点  

     Q.rear  尾指针 指向尾结点

  

     元素指针变化情况

          初始            Q.front = Q.rear

          有元素入队之后   Q.rear 后移 并指向该元素  Q.front指向头指针

          再有元素入队之后 Q.rear再次后移指向新元素

          出队时 从队头出队 第一个进入的元素最先出 Q.rear前移
*/

  

1.链式队列的定义
```
#define MAXQSIZE 100   // 最大队列长度

  

typedef struct Qnode{

     QElemType data;      // 数据域

     struct Qnode *next;  // 指针域

}QNode, *QueuePtr;  // 嵌套定义 自己定义自己

typedef struct{

     QueuePtr front;  // 队头指针

     QueuePtr rear;   // 队尾指针

}LinkQueue;
```



2.链队列的初始化
```
Status InitQueue(LinkQueue &Q){

     Q.front = Q.rear=(QueuePtr)malloc(sizeof(QNode));

     if(!Q.front)  exit(OVERFLOW);

     Q.front -> next = NULL;

     return OK;
}
```



3.链队列的销毁
```
// 从头结点开始 依次释放

Status DestoryQueue(LinkQueue &Q){

     while(Q.front){

          p = Q.front->next;  // 先保存要删除元素的next域(下一个元素的位置 指针域)

          free(Q.front);

          Q.front = p;   // 接着删除下一个元素

     }

  

     // 方法二

     /* Q.rear = Q.front -> next;    
	     free(Q.front);    
	     Q.front = Q.rear;
	*/
  
     return OK;
}
```

  
  
  4.链队列的入队  

/* 将元素e入队

     只能将元素入在队尾

     1.分配一个空间

     2.准备一个空指针

     3.将空指针指向新元素

     4.将新元素放在队中
*/
```
Status EnQueue(LinkQueue &Q, QElemType e){

     p = (QueuePtr)malloc(sizeof(QNode));   // 分配一块空的空间

  

     if(!p)  exit(OVERFLOW);                // 检验分配是否成功

  

     p -> data = e;

     p -> next = NULL;

  

     Q.rear -> next = p;

     Q.rear = p;

  

     return OK;
}
```

  

5.链队列出队

/*

     只能从队头出队

  

     p = Q.front -> next;    

     e = p -> data;

     Q.front -> next = p -> next;

     delete p;   或者free(p)

*/
```
Status DeQueue(LinkQueue &Q QElemType &e){

     if(Q.front == Q.rear)   return ERROR;

     p = Q.front -> next;

     e = p -> data;

     Q.front -> next = p -> next;

     // 如果删除的元素是最后一个元素时  即出队之后链队列为空队 则需要头指针和尾指针指向同一个位置

     if(Q.rear == p)    Q.rear = Q.front;

  

     delete p;

     return OK;

}
```

```
Status GetHead(LinkQueue Q, QElemType &e){

     if(Q.front == Q.rear)   return ERROR;

  

     e = Q.front -> next -> data;

  

     return OK;

}
```
