/*

     判断树: 用于描述分类过程的二叉树  eg.if语句转换成二叉树 一旦满足条件就退出

     可以通过改变判断的顺序提高整个判断过程的效率 -> 哈夫曼树  

  

     路径: 从树中一个结点到另一个结点的分支构成这两个结点间的路径

     结点的路径长度: 两结点路径上的分支数

     树的路经长度: 从树根到每一个结点的路径长度之和 TL

  

     权: 将树中结点赋给数值 该数值称为结点的权 权重

     结点的带权路径长度: 从根结点到该结点之间的路径长度与该结点权的乘积

     树的带权路径长度WPL: 树当中所有叶子结点的带权路径长度之和

                         (每一个结点的权和路径长度的积 的和)

  

     eg.       A               D的带权路径长度为 2*7 = 14

          B         C          E的带权路径长度为 2*5 = 10

        D   E      F   G       F的带权路径长度为 2*2 = 4

       (7)  (5)   (2)  (4)     G的带权路径长度为 2*4 = 8

       这棵树的带权路径长度为 14+10+4+8 = 36

     哈夫曼树: 最优树 带权路径长度最短的树(前提是树的度是一样的)

  
     满二叉树不一定是哈夫曼树

  
     权重大的放在前面 树的带权路径长度就短

     贪心算法思想: 哈夫曼树中权越大的叶子离根越近 构造哈夫曼树时优先选择权小的叶子结点

*/



/* 哈夫曼算法: 构造哈夫曼树的方法

  

     1.根据给定的权 w1 w2 w3... 构成n个二叉树的森林 F={T1, T2, ... , Tn}

       其中Ti只有一个带权为wi的根结点  

        -> 构造森林全是根

  

     2.在森林F中选取两个根结点的权值最小的树作为左右子树 构造一个新的二叉树

       且设置新的二叉树的根结点的权值为其左右子树上根结点的权值之和

       -> 选用两小造新树

  

     3.在森林F中删除这两个树 同时将新得到的二叉树加入森林

       -> 删除两小填新人

  

     4.重复2.3.步骤   依次拿出两个最小的树 直到森林中只有一个树 这棵树及时哈夫曼树

  

     口诀: 构造森林全是根 选用两小造新树 删除两小添新人 重复步骤剩单根

  

     eg. 有4个结点 a b c d 权值分别为7 5 2 4 构造哈夫曼树

          1.将权值最小的c d两个结点拿出来

          2.给这两个结点加一个双亲(权重为6) 形成二叉树 双亲结点的权重为这两个结点的和

          3.把森林中c d结点删除

          4.把b和刚设置的双亲结点(权值为6)拿出来 再设置一个双亲结点(权重为11) 形成一个二叉树

          5.把b结点从森林中删除

          6.把a和刚设置的双亲(权重为11) 拿出来 再设置一个双亲结点(权重为18) 形成一个二叉树

  

                   18

          7(a)        11

                   5(b)       6

                         2(c)      4(d)

  
     哈夫曼树中结点度数为0或2 没有度为1的结点

     包含n个叶子结点的哈夫曼树中共有2n-1个结点

  
     初始时有n个二叉树 要经过n-1次合并 产生n-1个新结点 因此哈夫曼树中一共有2n-1个结点

*/

/* eg. 有n=8 权值W={7, 19, 2, 6, 32, 3, 21, 10}构造哈夫曼树

     数组[16] 取1-15的下标

  
     初始化:    输入初始n个叶子结点: 置HT[1...n]的weight值

               HT [1....2n-1]: lch=rch=parent=0;

  
     创建一个循环:   进行以下n-1次合并 依次产生n-1个结点HT[i], i= n+1 ... 2n-1

  
               for(i=1; i<=(2n-1); i++){

                    在HT[i]选取两个权值最小的结点HT[s1] HT[s2]

                         HT[s2].parent=i;

                         HT[i].rch = s2;

                    重复这个过程

                    直到只剩下一个根

               }
*/

```
void CreateHuffmanTree(HuffmanTree HT, int n){

     if(n <= 1){

          return;

     }


     m = 2*n-1;   // 数组共有2n-1个元素


     HT=new HTNodse[m+1];   // 0下标不使用 HT[m]表示根结点

  
     for(i=1; i<=m; ++i){

          // 将2n-1个元素的lch、rch、parent置为0

          HT[i].lch = 0;

          HT[i].rch = 0;

          HT[i].parent = 0;

     }


     for(i=1; i<=n; ++i){

          // 输入前n个元素的weight值

          cin >> HT[i].weight;

     }


     // 初始化结束 下面开始建立哈夫曼树

     for(i=n+1; i<=m; i++){

          // 合并产生n-1个结点 构造哈夫曼树

          Select(HT, i-1, s1, s2);   // 此处写了一个函数

          // 在HT[k](1<=k<=i-1)中选择两个其双亲域为0,

          // 且权值最小的结点 并返回它们在HT中的序号s1和s2

  

          HT[s1].parent=i;   // 表示从F中删除s1 s2

          HT[s2].parent=i;

          HT[i].lch=s1;      // 分别将s1 s2设置为左孩子和右孩子

          HT[i].rch=s2;

          HT[i].weight=HT[s1].weight + HT[s2].weight;  // i的权值为左右孩子权值之和

     }
}
```

// 哈夫曼编码算法实现
```
void CreateHuffmanCode(HuffmanTree HT, HuffmanCode &HC, int n){

     // 从叶子到根逆向求每个字符的哈夫曼编码 存储再编码表HC中

  
     HC = new char *[n+1];   // 分配n个字符

     cd = new char [n];      // cd数组就用来存储这个中间得到的二进制数值

     cd[n-1] = '\0';         // 编码结束符 就是二进制数值的最后一位

  

     for(i=1; i<=n; ++i){

          start=n-1;

          c = i;              // 选择的结点

          f = HT[i].parent;   // 选择的结点的双亲      f=0处为根结点

  
          while(f != 0){  

               // 选择好结点后 向上寻找这个结点的双亲结点 然后再找这个双亲的双亲结点

               // 当f寻找到0的时候 即已经判断到根结点了 f=0 结束这个循环

  

               --start;  // 再向上判断其双亲

  

               if(HT[f].lchild == c){   // 如果这个双亲的左孩子是判断的结点 -> 0

                    cd[start] = '0';  // 结点为双亲的左孩子lchild 返回一个0

               }

               else{  // 如果不是左孩子就是右孩子 -> 1

                    cd[start] = '1';  // 结点为双亲的右孩子rchild 返回一个1
               }

  
               c=f;   // 继续进行回溯 判断下一个结点

               f=HT[f].parent;

          }

  

          HC[i] = new char [n-start];  // 为第i个字符串编码分配空间

          strcpy(HC[i], &cd[start]);   // 将求得的编码从临时空间cd复制到HC的当前行中

     }

     delete cd;  // 释放临时空间

}// CreateHuffmanCode;

```

/*

     路径: 接续的边构成的顶点序列

     路径长度: 路径上边或弧的数目、权值之和

     回路(环): 第一个顶点和最后一个顶点相同的路径

     简单回路(简单环): 除路径起点和终点相同外 其余顶点均不相同的路径

  
     连通图: 图G = (V, E)中 对任何两个顶点v、u都存在从v到u的路径 则称G是连通图 (无向图)

     强连通图 有向图

  
     权: 图中边或弧所具有的相关数 表明从一个顶点到另一个顶点的距离或耗费

     网: 带权的图

  
     子图
  

     连通分量(强连通分量): 无向图G的极大连通子图

     极大连通子图: 已知为连通子图 将G中加入任意一个新的顶点 子图就不再连通了

     极小连通子图:                   删除任意一个新的顶点 子图就不再连通了

  
     生成树: 包含无向图G所有顶点的极小连通子图

     生成森林: 对非连通图 由各个连通分量的生成树的集合

/* 图的遍历: 找每个顶点的邻接点的过程

     由于在遍历时会产生回路 也就是往一个方向到了死路就要往回走

  

     我们定义一个辅助数组visited[n] 用来标记被访问过的顶点

          如果被访问过了 经过回路时不再访问它

     初始状态visited[i] = 0

     顶点被访问时 visited[i] = 1

  

     我们首先有一个图 然后我们做出它的邻接表 同时我们创建一个辅助数组 没访问之前全是0

     然后依次访问设为1 来回回溯

     同时我们创建一个栈 正向访问元素时 把每一个结点进展 同时visited=1

     访问完了之后回溯 把每个结点出栈 遇到1就不访问 然后换一个路线再次进栈

     图的常用遍历方法:

          1.深度优先搜索算法dfs 一条路走到黑 当这条路没有能走的方向了才回到上一个位置重新判断 一直回到起点

          2.广度优先搜索算法bfs 先遍历第一层的所有点 然后遍历第二层的所有点 以此类推

          遍历顺序不唯一

  

          深度和广度搜索的空间复杂度相同 时间复杂度与存储结构有关(邻接矩阵或邻接表)

*/

```
               DFS(G, w);

          //w是v的邻接点，如果w未访问，则递归调用DFS

     }

}
```
