顺序表的链式存储结构

/* 链式表示又称非顺序影响或链式映像

     结点在存储器中是任意的 逻辑上相邻物理上不一定相邻

     在存储每一个元素的同时 还存储下一个元素在哪 最后一个元素的指针域为空 "^"

     ^=NULL=0

  
     存储数据(数据域)的同时需要存储指针(指针域) 也称列

  
     链表 单链表   通过指针联系到一起

     头指针: 记录第一个元素的地址


     结点: 数据元素的存储映像 由数据域和指针域两部分组成

     链表: n个结点由指针链促成一个链表


     头指针H(head) -> 头结点 ->  a1,(下一个元素的地址)(首元结点)  
     ->  a2,()  -> ... -> an, ^
*/

  

/*

     单链表(线性链表): 结点只有一个指针域的链表 (可以用头指针名字命名)

     双链表: 结点有两个指针域的链表 一共指针域指向前驱指针 另一个指针域指向后继指针

     循环链表: 链表的首尾相接 最后一个元素指针域不是^ 是第一个元素的指针域

  

     首元结点: 存储第一个元素的结点

     头结点: 在链表的的首元结点前附设的一个结点 便于表示首元结点 便于处理空表

     1.不带头结点的链表

     2.带头结点的链表

  

     表示空表: 无头结点时 头指针为空表示空表

               有头结点时 当头结点的指针域为空时表示空表

  

     结点在存储器中位置是任意的 没有物理逻辑

     顺序存储法: 访问时通过指针与查找数据

          因此查找每个数据花费时间不同 第一个结点块 最后一个结点慢

*/

  

/* 单链表的存储结构 结构体

     定于数据需要指明数据类型 data: ElemType

第三个算法 单链表销毁    

/*

     从头指针开始 依次释放

     头指针中地址域指向头结点 可以释放头结点   P = &L  

     头结点中地址域指向首元结点 可以释放首元结点

  

     不能直接删掉头指针中的地址域(头结点) 这样会失去头结点 影响首元结点的销毁

     因此将L指向的位置向后移 指向第二个元素 L = L -> next   !!!此处如何实现

     然后就可以进行删除 c++:delete p; (new)   c:free(p); (malloc)

  

     每一次删除后 都让L地址指向下一个元素 然后再删除原本指向的地址元素

     这样下一步要删除的元素地址就不会找不到

  

     最后一个元素 吧最后一个元素的指针域 ^  复制给L 删除最后一个元素

     即循环结束条件: L== NULL == ^

     如果L不是空 L!=NULL或L 证明循环还要继续进行 直到L==NULL为止

*/  
```
Status DestoryList_L(LinkList &L){

     Lnode *p;             // 或LinkList p;

     while(L){

          p = L;           // 让p指向L

          L = L -> next;   // 让L指向下一个结点 第一次是第二个结点(首元结点之后的结点·1)

          delete p;

     }

     return OK;

}
```

  
  
算法三 清空链表

/* 链表仍存在 但无元素 成为空链表

     头指针和头结点仍存在

     思想: 依次释放所有结点 并将头系欸但指针域设置为空

  

          P = L -> next  

          q = p -> next

          delete p;

  

     q指向p的下一个元素  因此可以删除p

     反复执行该操作

  

          p = q;

          q = q -> next;

     删除一个p之后 将p定义到q的位置 再让q指向下一个位置

     上述两句不能交换位置

     直至p为空 即当p指到^ 时p为空结点

  

     结束条件p == NULL    若p != L则继续进行该循环

*/
```
Status ClearList(LinkList &L){  // 将L重置为空表

     Lnode *p, *q;              

     p = L -> next;

     while(p){                  // 没到表尾

          q = p -> next;

          delete p;

          p = q;

     }

     L -> next = NULL;          // 头指针域为空

     return OK;

}
```

  
  
算法四 求链表长

/* 从首元结点开始 依次计数所有结点

     每访问一个数据地址 记一次 i

     最后访问到^ 时  i的值就是表长

*/
```
int ListLength_L(LinkList L){    // 返回L中的数据元素个数

     LinkList p;

     p = L -> next;              // p指向第一个结点

     i = 0;

     while(p){                   // 遍历单链表 统计结点数

          i++;

          p = p -> next;

     }

     return i;

}
```


  
算法五 取单链表中的第i个元素的内容

/*

     从链表的头指针出发 顺着链域next逐个结点往下搜索 直到搜索到目标个数第i个结点为止

     不是随机存取结构

  

     算法步骤

          1.从第一个结点(L -> next)顺链扫描 用指针p指向当前扫描的结点 p初值 p = L -> next

          2.j做计数器 累计当前扫描过的结点数 j初值为1

          3.当p指向扫描到的下一结点时 计数器j加1

          4.当j == i时 p所指的结点就是要找的第i个结点

*/
```
Status GetElem_L(LinkList L, int i, ElemType &e){    

     // 获取线性表L中的某个数据元素的内容 通过变量e返回  e是返回值 &e为引用数据类型

     p = L -> next;  j = 1;          // 初始化

     while(p && j < i){              // 向后扫描 直到p指向第i个元素或p为空

          p = p -> next;  ++j;

     }

     if(!p || j > i)  return ERROR;  // 第i个元素不存在

     e = p -> data;                  // 取第i个元素 循环结束后将i的值赋给e 通过e带回

     return OK;

} // GetElem_L
```

  
  
算法六 根据指定数据寻找并获取数据位置

/* 每次访问数据 将数据与指定数据e比较 直至相同

     p = L -> next   p = p -> next   p -> data != e

  

     算法步骤:

          1.从第一个结点算起 依次与e相比较

          2.如果找到一个值与e相同的数据元素 则返回此数据的地址

          3.如果访问所有数据元素后没有与e值相同的数据 则返回NULL

*/
```
Lnode *LocateElem_L(LinkList L, ElemType e){

     // 在线性表L中查找值为e的数据元素

     // 找到 返回元素地址 未找到返回NULL

     p = L -> next;

     while(p && p -> data != e)

          p = p -> next;

     return p;

}
```
该算法的时间复杂度是O(n)

算法七 插入

/* 在第i个结点前插入一个e

     a(i-1)  e  a(i)

  

     让原来数据的前驱(i-1)的后继成为这个新元素e  修改前驱(i-1结点)的next域 为新元素e

     让原来数据(i)的前驱成为这个新元素e          修改插入元素e的next域 为原来的元素(i)

  

     1.首先找到a(i-1)的存储位置p  ( a(i-1), p )

     2.生成一个数据域为e的新结点s   s (e, )

     3.插入新结点 新结点的指针域(next)指向ai 结点a(i-1)的指针域指向新结点  顺序不能更改

  

          s -> next = p -> next; // p -> next(ai)赋给s -> next  这样p -> next目前为空  s -> next 为a(i)的地址

  

          p -> next = s          // 将s赋给 p -> next  这样 p -> next 为e的地址

*/

  

 在L中第i个元素之前插入数据元素e
```
 Status ListInsert_L(LinkList &L, int i, ElemType e){

     p = L;  j = 0;

  

     while(p && j < i-1){

          p = p -> next; ++j;    // 寻找第i-1个结点 p指向i-1结点

     }

     if (!p || j > i-1)  return ERROR;  // i大于表长+1或者小于1 插入位置非法

  

     s = new LNode;  // 生成一个新的空间

     s -> data = e;  // 生成新结点s 将结点s的数据域置为e    s(e, data)

  

     s -> next = p -> next;   // 将结点s插入L中 s的地址内是a(i)

     p -> next = s;           // p的地址域是e

  

     return OK;

} // ListInsert-L
```
时间复杂度为O(1)

  
  
算法八 删除第i个结点

/*   a(i-1)  a(i+1)

     修改前驱的指针域 改为后继

  

     算法步骤:

     1.找到a(i-1)的存储位置p    保存要删除的a(i) 相当于回收站

     2.令 p -> next 指向a(i+1)  

          原本p -> next指向a(i) 那么p -> next -> next指向a(i+1)

          p -> next = p -> next -> next;

          这样p -> next就指向a(i+1)的地址

     3.释放ai的空间

*/
```
Status ListDelete_L(LinkList &L, int i, ElemType &e){

     p = L;  j = 0;  q=0;

     while(p -> next && j < i-1){

          p = p -> next; ++j;                   // 寻找第i个结点 并令p指向其前驱

     }

     if(!(p -> next) || j > i-1) return ERROR;  // 若删除位置不合理

  

     q = p -> next;          

     // 临时保存被删结点的地址以备释放

     // 把p->next也就是a(i)的地址给q 那么现在q指向a(i) p此刻是a(i-1)

  

     p -> next = q -> next;    

     // 改变删除结点的数据域

     // 已知q现在是a(i) 那么q->next是a(i+1) 即p->next为i+1 得到 p->next->next 此时p->next为a(i+1)的地址

  

     e = q -> data;            // 保存删除结点的数据域 相当于回收站 q的数据为a(i)

     delete q;                 // 释放删除结点的空间

return OK;

} // ListDelete_L
```
 时间复杂度为O(1) 
 如果要在单链表中进行前插或删除操作 由于要从头查找前驱结点 时间复杂度为O(n)

  

单链表的建立

/* 头插法 每次把新元素插在链表的头部

     1.从一个空表开始 重复读入数据

     2.生成新结点 将读入的数据存放到新结点的数据域中

     3.从最后一个结点开始 依次将各结点插入到链表的前端

  
     假设有一个链表L(a,b,c,d,e)

     创建一个空表 首先将e放进去 然后将d放在e的前面 然后将c放在d的前面 然后将b放在c的前面 最后将a放在b的前面

  

     操作方法: 假设将e放进去后 修改头指针的指针域 将其指向d 然后使d的指针域指向e 就是将d放在了e的前面

*/
```
// 1.建立一个头结点

L = new LNode;          // c语言中 L = (LinkList)malloc(sizeof(LNode));

  

// 2.令头结点的指针域为空

L -> next = NULL;

  

// 3.定义结点

p = new LNode;

p -> data = a(n);       // a(n)为链表中最后一个元素

  

// 4.插入结点  新结点接在头结点后面 把已经插入的接在新结点后面

p -> next = L -> next;  // L = -> next为空 所以此处p -> next也为空

L -> next = p;          // p成为了L的下一位元素 成功插入到链表

  

// 5.插入倒数第二个元素

p = new LNode;

p -> data = a(n-1);

  

p -> next = L -> next;  // L是头指针 L->next为头指针后的第一个元素 将此元素定位 L->next即往最前面插入了一个元素

L -> next = p;

  

// 6.循环上一个步骤 至第一个元素

void CreateList_H(LinkList &L, int n){

     L = new LNode;

     L -> next = NULL;           // 先建立一个带头结点的单链表

  

     for(i = n; i > 0; --i){

          p = new LNode;         // 生成新结点 p = (LNode*)malloc(sizeof(LNode));

          cin >> p >> data;      // 输入元素值 scanf(&p -> data)

          p -> next = L -> next; // 插入到表头

          L -> next = p;

     }

} // CreateList_H
```
时间复杂度是O(n)

  

建立单链表 尾插法

/* 将元素插在链表的尾部

     1.从一个空表开始 将新结点逐个插入到链表的尾部 尾指针r指向链表的尾结点

     2.初始时 r同L均指向头结点 每读入一个数据元素则申请一个新结点 将新结点插入到尾结点后 r指向新结点

          开始数据(头结点和r)   插入一个数据后(头结点, 第一个数据r)

          每产生一个新的数据就改变一次r的位置 r始终跟着最后一个数据

          操作实现 p -> data = a;    

                  p -> next = NULL;

                  r -> next = p;

                  r = p;

*/

正位序输入n个元素的值 建立带表头结点的单链表L
```
void CreateList_R(LinkList &L, int n){

     L = new LNode;      L -> next = NULL;

     r = L;    // 尾指针r指向头结点 初始时头指针和尾指针重合

  

     for(i = 0; i < n; ++i){

          p = new LNode;   cin >> p -> data;  // 生成新结点 输入元素值

          p -> next = NULL;

          r -> next = p;  // 插入到表尾 是新结点成为最后一个元素

          r = p;  // r指向新的尾结点  让尾结点指向新的结点

     }

}
```
时间复杂度为O(n)

  

循环链表

/* 最后一个结点的指针域指向头结点

     优点 从表中任意结点出发可找到表中的其他元素

     判断是否指到最后一个元素 看指针域是否指向头指针

     循环条件 P != L    p -> next != L

  

     找a1的时间复杂度 O(1)

     找an的时间复杂度 O(n)

     操作复杂

  

     创建尾指针R

          a(1)的存储位置是 R -> next -> next

          a(n)的存储位置是 R

     时间复杂度都是O(1)

*/

  
  
// 将两个带尾指针的循环链表合并

/* a1 a2 ... an     b1 b2 ... bn

     p存表头结点                            p = Ta -> next;

  

     两个链表 让an的下一个元素为b1           Ta -> next = Tb -> next -> next;

     将第二个链表的头结点删除 释放b的头结点   delete Tb -> next;

     bn的指针域指向a的头结点 修改指针        Tb -> next = p;

*/
```
LinkList Connext(LinkList Ta, linkList Tb){  // 假设Ta Tb都是非空单循环链表

     p = Ta -> next;                  // p存放表头结点

     Ta -> next = Tb -> next -> next; // Tb表头连接Ta表尾

     delete Tb -> next;               // 释放Tb表头结点  或者 free(Tb -> next);

     Tb -> next = p;                  // 修改指针

     return Tb;

}
```
时间复杂度O(1)

双向循环链表  

/* 让头结点的前驱指针指向链表的最后一个结点  让最后一个结点的后继指向头结点

     双向链表结构的对称性: p -> prior -> next   =   p -> next -> prior

          即某元素的前驱结点的后继结点就是这个元素自身

  

     双链表的ListLength GetElem等算法与单链表相同

            插入 删除算法不同 且时间复杂度都为O(n)
*/

  

双链表的插入算法

/*  已知元素 a  ,  b(B, p)

     现在创建一个元素e(X, s) 要将x元素插在a b中间

     首先分配一个新结点 并使用一个指针s指向新结点 并为新数据的data域赋值

  
     1.将新结点的前驱指针赋值为前驱元素   s -> prior = p -> prior;

     2.修改前驱元素的后继为新结点        p -> prior -> next = s;    

  
     3.将新结点的后继指针赋值为后继元素   s -> next = p;

     4.修改后继元素的前驱为新结点        p -> prior = s;

*/
```
void ListInsert_DuL(DuLinkList &L, int i, ElemType e){

     // 在带头结点的双向循环链表L中的第i个位置之前插入e

  

     if(!(p = GetElemP_DuL(L, i)))  return ERROR;

  

     s = new DuLNode;    

     s -> data = e;

     s -> prior = p -> prior;

     p -> prior -> next = s;

  

     s -> next = p;

     p -> prior = s;

  

     return OK;

} // ListInsert_DuL
```



双链表的删除算法

/* 已知双链表 a, b(B, p), c

     要将b元素删除

  

     a的后继改为c   p -> prior -> next = p -> next;

     c的前驱改为a   p -> next -> prior = p -> prior;

*/
```
void ListDelete_DuL(DuLink &Lm int i, ElemType &e){

     // 删除带头结点的双向循环链表L中的第i个元素,  并用e返回

  

     if(!(p = GetElemP_DuL(L, i)))  return ERROR;

  

     e = p -> data;

     p -> prior -> next = p -> next;

     p -> next -> prior = p -> next;

  

     free(p);

  

     return OK;

} // ListDelete_DuL
```

/* 已知双链表 a, b(B, p), c

     要将b元素删除

  

     a的后继改为c   p -> prior -> next = p -> next;

     c的前驱改为a   p -> next -> prior = p -> prior;

*/
```
void ListDelete_DuL(DuLink &L, int i, ElemType &e){

```
 时间复杂度为O(1)     如果需要查找删除元素所在位置 时间复杂度为O(n)

  

双向循环链表 牺牲了空间换取了极高的时间效率

顺序表 的时间效率高 查找速度快 但占用更大空间 存储密度小

存储密度 = 结点数据本身占用的空间 / 结点占用的空间总量    存储密度越大 空间利用越高

eg. 已知一个表元素 e(x, b) 存储密度为 = x占用字节 / x+b占用字节

/* 有序表的合并

     已知线性表La和Lb中的数据元素按值非递减有序排列,  

     现要求将La和Lb归并为一个新的线性表Lc, 且Lc中的数据元素仍按值非递减有序排列

     La = (1,7,8)  Lb=(2,4,6,8,10,11)  -> Lc=(1,2,4,6,7,8,8,10,11)

	依次从两个表中取最小的数 将比较后更小的数放在Lc中 然后再次从表中取最小的数 再次比较

     直到将一个表中所有数据全部取完 将另一个表中剩余数据放在Lc中

  

     算法步骤:

          1.创建一个空表Lc

          2.依次从La或Lb中取元素小的结点插入到Lc表的最后 直至其中一个表变空表、

          3.继续讲La或Lb中一个表的剩余元素插入到Lc中
*/
```
void MergeList_Sq(SqList LA, SqList LB, SqList %LC){

     pa = LA.elem;

     pb = LB.elem;  // 指针pa和pb的初值分别指向两个表的第一个元素

  

     LC.length = LA.length + LB.length;  // 新表长度为为待合并两表的长度之和

     LC.elem = new ElemType[LC.length];  // 为合并后的新表分配一个数组空间

  

     pc = LC.elem;                       // 指针pc指向新表的第一个元素

     pa_last = LA.elem + LA.length - 1;  // 指针pa_last指向LA表的最后一个元素

     pb_last = LB.elem + LB.length - 1;  // 指针pb_last指向LB表的最后一个元素

     while(pa <= pa_last && pb <= pb_last){  // 两个表都非空

          if(*pa <= *pb) * pc ++= *pa++;   
            
          // 依次取两表中较小的结点
          
          // 如果pa的指针小于pb的指针 就将pa赋值给pc 然后将pa和pc都自增1


          else *pc ++= *pb++;  
          
          // 如果pb的指针小于pa 就将pb赋值给pc 然后将pb和pc自增1
     }
          while(pa <= pa_last) *pc++=*pa++;   
          
          // LB表到达表尾 将LA中剩余元素加入LC


	      // 如果pa内元素剩余 则将pa中剩余元素存入pc 并使pa和pc都自增到pa元素取完


     while(pb <= pb_last) *pc++=*pb++;   

     // LA表到达表尾 将LB中剩余元素加入LC

	 // 如果pb内元素剩余 则将pb中剩余元素存入pc 并使pb和pc都自增到pb元素取完
	 
} // MergeList_Sq
```

空间复杂度为O(ListLength(La) + ListLengh(Lb))



/* 有序表的合并 (链表)

     两表

     用La的头结点作为Lc头结点                     Lc = pc = La;

     比较两个表的第一个元素的指针域 将小的(a)放进Lc pa -> data < pa -> data;                   pc -> next = pa;

  
     此时新表中有元素a  则pc指针指向该元素         pc = pa;

     La中拿走了一个元素 现在用第二个元素与Lb比较    pa = pa -> next;


     第二次比较 仍然将小的放进Lc(b)               pc -> next = pb;

                                                pc = pb;

                                                pb = pb -> next;

     重复这个过程 直到其中一个表的元素全部取完

     将另一个表的剩余元素加入Lc               pc -> next = pa ? pa : pb;

     释放Lb的头结点                              delete Lb;

  
     ?为判断 若?前面的东西成立 返回:前面的东西  若不成立 返回:后面的东西
*/
```
void MergeList_L(LinkList &La, LinkList &Lb, LinkList &Lc){

     pa = La -> next;    

     pb = Lb -> next;

     pc = Lc = La;     // 用La的头结点作为Lc的头结点

  

     while(pa && pb){  // 开始比较 放入元素 直到其中一个表元素为空

          if(pa -> data <= pb -> data){

               pc -> next = pa;  

               pc = pa;

               pa = pa -> next;

          }

          else{

               pc -> next = pb;

               pc = pb;

               pb = pb -> next;
          }
     }

  
     pc -> next = pa ? pa : pb;   // 插入剩余段

     delete Lb;   // 释放Lb的头结点
}
```

/* (二)使用链式存储结构

     链表中第一个元素昨为第一个结点

     A表 第一个元素7 0 第二个元素3 1 第三个元素9 8 第四个元素5 17

     B表 8 1   22 7   -9 8

  

     算法步骤:

          1.建立一个只有头结点的空链表

          2.生成一个新结点 *s

          3.输入多项式当前项的系数和指数赋给新结点*s的数据域

          4.设置一个前驱指针pre 用于指向输入的第一个元素的前驱    pre初值指向头结点

          5.指针q初始化 指向首元结点

          6.循环向下比较元素 找到第一个大于输入项指针的结点*q

          7.将输入项结点*s插入到*q之前

*/

```
// 定义该链表

typedef struct PNode{

     float coef;  // 系数

     int expn;    // 指数

     struct PNode *next;  // 指针域

}PNode, *Polynomial;

```



```
  // 案例二算法

void CreatePolyn(Polynomial &P, int n){

     // 输入m项的系数和指数 建立表示多项式的有序链表p

  

     P = new PNode;

     P -> next = NULL;   // 建立一个只有空结点的单链表

  

     for(i = 1; i <= n; i++){   // 依次输入非零项

          s = new PNode;        // 每一次循环都生成一个新结点

  

          cin >> s -> coef >> s -> expn;   // 输入系数和指数两个值 分别赋给coef和expn

          pre = P;      // pre用于保存q的前驱 初值为头结点      

          q = P -> next;   // q初始化 指向首元结点 q为元素插入的位置

  

          while(q && q -> expn < s -> expn){

               // 只要q不为NULL 且q小于s 就执行循环

               // 找到第一个大于输入项指数的项 *q

  

               pre = q;  // q为P的下一个数值 将pre往下更新一个位置

               q= q -> next;

          }

          s -> next = q;  // 当找到了合适的插入位置 或者q遍历到表尾 将新结点s的next指向q

          pre -> next = s;  // 将pre的next指针域指向新结点s 完成降序插入元素
     }
}
```

/* 算法步骤:

     1.指针p1和p2初始化 分别指向Pa和Pb的首元结点

     2.p3指向和多项式当前的结点 初值为Pa的头结点

     3.当指针p1和p2均未到达相应的表尾时 则循环比较p1和p2所指结点对应的指数值

          情况一: p1 == p2  系数相加

               情况1: 和不为0 修改p1所指结点的系数值 同时删除p2所指结点

               情况2: 和为0 删除p1和p2所指的结点

          情况二: p1 < p2  取p1所指结点 插入到"和多项式"链表中去

          情况三: p1 > p2  取p2所指结点 插入到"和多项式"链表中去

          当其中一个表元素已经取空 则该步骤结束

     4.将剩余非空多项式的元素插入到p3所指结点之后

     5.释放pb的头结点
