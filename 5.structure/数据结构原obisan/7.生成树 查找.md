/* 生成树

     生成树: 所有顶点由边连接在一起 但不存在回路的图

  

     一个图可以有许多不同的生成树

     所有的生成树: 1.生成树顶点个数与图顶点个数相同

                  2.生成树是图的最小连通子图 去掉一条边则非连通

                  3.一个有n个顶点的连通图的生成树有n-1条边

                  4.在生成树中再加一条边必然形成回路

                  5.生成树中任意两个顶点间的路径是唯一的

  

     深度优先生成树 从一个路走到最里面没有继续可以走的路 所有点连成一条线

     广度优先生成树 从起点连接所有平行位置线 然后继续向下 直到所有点都连上了

  

     最小生成树 最小代价生成树

     根据每条连线的权值不同 我们可以连接权值最小的一种线的全图 为最小生成树

  

     构造最小生成树Minimum Spanning Tree   MST (贪心算法一种)

     MST性质 1.首先有一个无向图V

             2.无向图中有顶点已经落在生成树上 顶点集合U

             3.还有一些顶点没有在生成树中 V-U

             4.接下来在所有连通的顶点U中 和V-U顶点连接的边中选择权值最小的边 选择的边不能连接完是回路

  

             起始时 U={u0}(u0∈V)  TE={} TE是最小生成树边的集合

             找权值最小的边 将这条边放在TE里 同时把顶点放入U

             持续这个过程至U=V 所有顶点进入最小生成树

     构造最小生成树方法一: 普里姆算法(Prim)

     已知U中一个顶点 然后选择和这个顶点相连的最小权值线 把对应顶点加入U

     继续找这两个定点有关的权值最小线 不能回路 直到所有顶点加入U

     构造最小生成树方法二: 克鲁斯卡尔算法(Kruskal)

     我们认为图中没有线 只有很多顶点 直接选择权值最小的线 把两个顶点加入U 线加入TE

     然后再直接拿出权值最小的线 不能回路 线与线之间可以没有关系 直到所有顶点连上线

  

     两种算法比较:

          普里姆   选择点 O(n²)  适合稠密图

          克鲁斯卡 选择边 O(边数) 适合稀疏图

*/

  

/* 构造最小生成树的应用一 最短路径问题

     在有向网中A点到B点的多条路径中选择权值最短的路径 即最小路径

  

     第一类问题: 两点间最短路径问题 从一个点到另一个点多种走法 选择权值最小走法

     第二类问题: 某源点到其他各点最短路径 从一个点到所有位置的路径长度 选怎权值最小的点

  

     单源最短路径 Dijkstra迪杰斯特拉算法

     所有顶点间的最短路径 Floyd弗洛伊德算法

  

     Dijkstra算法(适用于单源最短路径)

          初始时令S={v0} T={其余顶点}

          T中顶点对应距离值用辅助数组D存放

  

          1.初始化 先找出从源点(S/v0)到各终点(V-S)的直达路径 即一条可以到达该处的弧

               此时可以构建出一个初始二维表

          2.从所有路径中选择权值最短(进入S)

  

          3.然后对其余路径(T=V-S)进行调整 如果存在更小的就替换

               依次添加每个结点 观察有没有比元素数值权值更小的走法

               有的话就代替原始数组的值

  

               比如我有v0 v1 v2 v3  不考虑他们的复杂连线 先把两两相连的数值写出一个初始表

               然后以v0为起点 添加v1   看v0到v1 v2 v3有没有因为v1的加入 考虑经过结点的连线

               产生了更小的路径 然后代替原来的直线到达

  

               判断的后期不是按照顺序 是按照 这一组最短路径中选择最小的一个路径

               再添加它看有没有改变的路径

  

          4.直到所有的都选完了(S=V T=0)  找到了从v0出发到所有顶点的最小路径

  
  
  

     Floyd算法(所有顶点间的最短路径)

          要计算所有顶点间的最短路径 方法一: 每次以一个顶带你为源点 重复执行Dijkstra算法

          方法二: Floyd算法

               1.逐个顶点试探

                    比如我有A B C 依次添加这三个顶点 去试探其他顶点之间的最短路径

                    有连线的两个顶点间有一个权值 仍然可以写一个初始表

                    没有连线的位置写∞ 对角线写0

                    加入A 我们可以通过A从B到C 从B到A 从C到A 同理其他路径

                    然后看有没有更小的走法 代替原表数值

                    (比如原来A->C 10 加入B后 A->B->C 7 就可以代替10)

                    也可能原来没有连线 直接添加数值

  

               2.从vi到vj的所有路径

               3.选最短的那条

*/

  

/* 构造最小生成树的应用二 有向无环图

     不构成回路 可以是闭合的图形 但是方向上不是回路

  

     AOV网: 用一个有向图表示一个工程的子工程间相互制约 顶点表示活动 弧表示活动之间的优先制约

          关系，称这种图为顶点表示活动的网 简称AOV网

           i->j i为前驱 j为后继  <i,j>

           AOV网中没有回路

  
  

     AOE网: 用一个有向图表示一个工程的子工程间相互制约 弧表示活动 顶点表示活动的开始或结束

          关系，称这种图为弧表示活动的网 简称AOV网

  

     拓扑排序例 排课表(要先上前置课 才能上下面的课)

     拓扑有序序列: AOV网没有回路的前提下 把所有活动排成一个线性序列

          <i,j> i一定排在j的前面(前置课) 具有这种性质的线性序列叫拓扑有序序列

  

     方法: 1.在有向图中选一个没有前驱的顶点且输出之

           2.从图中删除该顶点和所有以它为尾的弧

           翻译: 从头开始 选择删除一个没有前驱的点 依次执行 直到没有这样的点结束

                 如果都删掉了 构造成功 得到了一个一维链 不唯一 最小生成树

                 如果最后剩下几个元素 都有前驱无法删除 说明是环

           其中: 某元素的前驱必须出现在序列中该元素的前面

  

     我们可以用拓扑排序检验AOV网中是否存在环 就是循环完之后 网中剩下了元素 都有前驱

*/

/* 构造最小生成树的应用三 图的关键路径

     边表示活动 边的权值表示持续时间 顶点表示事件 事件表示上一个活动结束 下一个活动开始

     头顶点 源点   尾顶点 汇点

  

     考虑问题: 1.完成整项项目需要多少时间

               2.哪些活动是影响整个项目进度的关键(图的关键路径)

  

     图的关键路径: 路径长度最长的路径

     路径长度: 路径上各活动的持续时间之和

  

     ve(vj) 事件vj的最早发生时间

     vl(vj) 事件vj的最迟发生时间

     e(i) 活动ai的最早开始时间

     l(i) 活动ai的最迟开始时间

     l(i)-e(i) 完成活动ai的时间余量

     关键活动 l(i)==e(i)的活动 差值l(i)-e(i)==0的活动

  

     求值: 1. e(i) = ve(j)

           1. l(i) = vl(k) - 持续时间

           2. ve(i) 从前往后递推 取最大的时间

           3. vl(j) 从后往前递推 取最小的时间

     求关键路径: 1.求ve(i) vl(j)

                 2.求e(i) l(i)

                 3.计算l(i)-e(i)   == 0 关键路径

  

     eg. 已知一个图

          1.首先从头开始 第一个点最早时间为0 然后算每个顶点的最早时间     ------> ve

          上一个顶点+权值 取最大的

          2.然后从尾开始 最后一个顶点的最晚时间和最早时间相等            ------> vl

          然后用这个最末时间减去权值 得到上一个顶点的最晚时间 取最小的

  

          3.得到了每个顶点的最早时间和最晚时间 的表

          然后计算活动时间(边进行的时间) 用边的尾减边的头

          比如起始a1活动 v1和v2顶点 用v1的最晚时间减去v1的最早时间        ------>e

          得到该边的最早时间 v2的最晚时间减去最早时间 得到该边的最晚时间   ------>l

  

          4.相减 l-e 得到差值的差值 差值为0的就是关键活动

          5.所有关键活动的连线 就是关键路径
